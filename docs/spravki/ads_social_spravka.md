## Источники и пути

- **Авито**: браузер пользователя (Claude in Chrome), `avito.ru/moskva_i_mo/predlozheniya_uslug?q=забор+под+ключ`. Сначала страница «Доступ ограничен: проверка безопасности — Проверка пройдена, перенаправление» (автоматическая проверка без капчи), затем выдача: 18 256 объявлений. Снята стр. 1 (50 объявлений) через DOM (`data-marker="item"`, `badge-title`, текст «Продвинуто»). При переходе на стр. 2 расширение ответило «This site is blocked by your site permissions» — съём остановлен. Из облака: curl — HTTP 400, Playwright — HTTP 429 «Доступ ограничен: проблема с IP» с кнопкой капчи; капча не проходилась.
- **Яндекс Карты**: облако, Playwright без входа, `yandex.ru/maps/213/moscow/search/<запрос>/` (переадресация на yandex.com/maps, интерфейс на английском), список прокручен 6 раз. Данные из состояния страницы (`script.state-view` → `stack[0].results.items`) и ответов `/maps/api/search`. Признак рекламы — блок `advert` в карточке с маркировкой ОРД (`ordInfo`: рекламодатель, ИНН), поля `isPriorityCampaign` (приоритетное размещение), `isDirect` (геообъявление Директа), `products` (витрина с ценами), `actionButtons` (кнопка), `promo.promoAction` (акция), `hasStories`. В тексте списка слово «Реклама» не выводится — рекламные карточки отличаются по данным, на скриншоте видны логотипы на метках.
- **2ГИС**: облако, Playwright, `2gis.ru/moscow/search/<запрос>` и `/page/2`, `/page/3`. Пометка «Реклама» и юрлицо стоят в тексте карточки. Три запроса о заборах ведут в одну рубрику «Заборы и ограждения» (1 295 мест) — выдача у них одинаковая. Баннеры площадки между карточками (Сбер Прайм АО «ЦПЛ», ООО «Платформа», ООО «Флаувау») отмечены отдельно.
- **Яндекс Услуги**: облако, curl, `uslugi.yandex.ru/213-moscow/category?text=<запрос>&p=<стр>`, состояние страницы (`search.workerIds`, `workers.items[].isAdvertised`, `search.direct`, `search.garantDirect` с `legalInfo`). По 10 исполнителей на страницу. Счётчик `totalItems` растёт с номером страницы (178 → 345 → 483) — как оценка размера выдачи не используется.
- **Профи.ру**: из облака HTTP 418 (curl и Playwright), `msk.profi.ru` — ошибка туннеля прокси.
- **ВКонтакте**: поиск по записям из облака требует входа; SeedHunter из облака без входа открывает только лендинг; браузер пользователя после блокировки Авито перестал пускать сайты, затем отключился.
- **Telegram / MAX**: TGStat — поиск по публикациям только после входа (бесплатно 20 постов за 7 дней); Telemetr — страница поиска 404.

## Наблюдения

Без неё — позиции 1, 2, 19, 20, 25, 46; первые две занимает один продавец с 223 отзывами и значками «Документы проверены» и «яПомогаю». [ОГРАНИЧЕНИЕ] XL и выделение цветом по карточкам не различаются: высота 236–342 px зависит от блока прайса. n = 1 запрос, 1 страница.
2. **Авито: кто продаёт.** [ФАКТ] 20 названий продавцов, 10 объявлений частных мастеров, у 3 продавец не показан. - **«ВК-таргет и Макс работают в стройке».** [ФАКТ] Новых данных по ВК в волне 2 нет (причины ниже). По волне 1: промопосты — у 1 из 10 (Мастеровит, 6 за 7 недель), посев — у 1 (Заборово). MAX у 7 из 10 стоит на сайте как чат или бот. [ВЫВОД] Снаружи нельзя ни подтвердить, ни опровергнуть: таргет без поста на стене и посевы в Telegram/MAX без входа в сервисы мониторинга не видны. Видимые деньги конкурентов вне Директа — Яндекс Карты (6 из 10) и Авито (2 из 10 точно, ещё 1 по названию). Проверка — только своим тестом с метрикой «цена заявки».
- **«Ворота через Авито — 400–700 ₽ за заявку».** [ОГРАНИЧЕНИЕ] Выдача Авито цену заявки не показывает; выдача «откатные ворота» не снята. [ФАКТ] В выдаче «забор под ключ» ворота упоминаются в 5 из 50 заголовков; 88% объявлений продвигаются платно, у продавцов с 2–8 отзывами и у продавца с 223 отзывами. ## Что не удалось и почему

- Авито: стр. 2 «забор под ключ», «установка забора» и «откатные ворота» (стр. 1–2), профили компаний (число объявлений, год регистрации) — после стр. 1 avito.ru заблокирован в настройках разрешений браузера; из облака — капча (HTTP 429). Нужен доступ к avito.ru в браузере пользователя; съём оставшегося — около 40 минут.
- ВКонтакте: SeedHunter (посевы по ключам «забор», «заборы», «откатные ворота», «забор под ключ» и названиям), поиск ВК по доменам — браузер пользователя недоступен, из облака нужен вход.
- Профи.ру — бот-защита (HTTP 418) из облака, браузер недоступен.
- Telegram / MAX — TGStat и Telemetr требуют входа; поиск посевов не выполнялся.
- 2ГИС по названиям «мастеровит», «проф-заборы», «доступные заборы» — «upstream request failed» из облака.
- Скриншоты Авито — не сохранены (блокировка наступила до съёма снимка).

## Безопасность

Капча не проходилась, входы и пароли не вводились, формы не отправлялись, продавцам не писали, «Показать телефон» не нажимался, рекламный кабинет «Дом гирлянд» не открывался. Имена частных мастеров (Авито, Яндекс Услуги) заменены на «частный мастер»; ИП названы как компании. Чужие вкладки браузера не трогались; своя вкладка с Авито осталась открытой — закрыть не дала блокировка сайта, вторая своя вкладка пустая; после отключения расширения закрыть их невозможно.
