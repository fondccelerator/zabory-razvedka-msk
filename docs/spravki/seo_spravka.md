# Этап «SEO»: кто из конкурентов держится на органике и за счёт чего

Заборы и откатные ворота, Москва и МО. Дата съёма: 20.10.2026. Видимость в выдаче — Keys.so, топ-10 Яндекса (Москва) по 9 запросам, период 05.09–05.10.2026 (собрано на прошлом этапе).

Версия 2 (20.10.2026): добавлены 4 домена облегчённого списка брифа (zabor-vam.ru, good-zabor.ru, moskovskie-zabory.ru, gorodzaborov.ru), индекс видимости показан в трёх вариантах, добавлено сравнение с органикой Similarweb. Замечания K1 и I5 из qa/checks_wave1.csv.

Термины:
- **Органика** — переходы из обычной (нерекламной) выдачи поисковика.
- **ИКС** — индекс качества сайта Яндекса: общая оценка полезности сайта и спроса на него, публикуется в Вебмастере.
- **sitemap** — файл со списком страниц для поисковика.
- **canonical** — метка основной версии страницы.
- **schema.org** — разметка, через которую поисковик понимает, где на странице организация, товар, цена, отзывы, вопросы.
- **TTFB** — время до первого байта ответа сервера.
- **LCP** — время отрисовки крупнейшего элемента первого экрана.
- **Гео-страница** — посадочная страница под город или район («заборы в Одинцово»).
- **Поддомен города** — отдельный адрес вида `odincovo.oblzabor.ru`.

## Источники и метод

| Что | Откуда | Как |
|---|---|---|
| Число и типы страниц | robots.txt и sitemap.xml каждого сайта (рекурсивно по индексам) | URL разложены по типам по словам в адресе (услуги, материалы, гео, статьи, FAQ, портфолио, видео, цены). Для 33zabora.ru, zabor-dlya-vseh.site, p-z-z.ru sitemap нет или он пуст — страницы найдены обходом ссылок с главной |
| Гео-страницы | те же URL | Совпадение с основами названий 300+ городов ЦФО (справочник hflabs/city) и населённых пунктов МО, на границе слова. Ручная выборочная проверка, ложные срабатывания («кирпич», «бежевый», «заборов») убраны |
| Поддомены | ссылки в HTML главной | Выборочная проверка 5 поддоменов у oblzabor.ru и dostup-zabor.ru, 2 у zabormo.ru и kupitzabor.ru: ответ, title, H1, canonical, robots.txt, sitemap, схожесть текста с основным доменом (difflib, первые 6000 знаков) |
| Мета, H1, schema, CMS, текст, видео, FAQ | HTML главной, страницы заборов (профнастил), гео-страницы, блога, портфолио | Python requests + BeautifulSoup. Слова — слова длиннее двух букв во всём тексте страницы, включая меню |
| TTFB | requests, один замер с облачного сервера через прокси | Абсолютные значения выше, чем у посетителя из Москвы |
| LCP, вес, адаптив | Playwright, мобильный экран 390×844, скриншоты в `img/seo/` | Облачная среда через прокси: абсолютные значения завышены, годятся только для сравнения сайтов между собой |
| Возраст домена | who.is (whois .ru/.site) | Дата текущей регистрации |
| ИКС и знаки Яндекса | webmaster.yandex.ru/siteinfo/?site=… | Капчи не было |
| Видимость в выдаче | data/serp_presence_msk.csv, data/keys_queries_msk.json, data/wordstat_dynamics.csv | Индекс видимости = Σ (частотность запроса × CTR позиции), три варианта: (А) широкая частотность Keys.so; (Б) точная частотность «!» — известна только для «забор под ключ» (14 205, сентябрь 2026), для 8 запросов не снята (дневной лимит Keys.so 20.10.2026), применён коэффициент 14 205 / 57 377 = 0,248; (В) без частотности — сумма CTR позиций. Кривая CTR — допущение: 1 — 28%, 2 — 15%, 3 — 10%, 4 — 7%, 5 — 5%, 6 — 4%, 7 — 3%, 8 — 2,5%, 9 — 2%, 10 — 1,8%. Все три — оценка в условных единицах, не переходы |
| Визиты | data/competitors.csv, data/traffic_channels.csv (Similarweb, июль–сентябрь 2026, весь мир) | Взяты без пересчёта; органика — визиты канала Search - Organic |

**Нагрузка на сайты.** Пауза между запросами скриптов 1,2–1,5 с. Скриптами — не более 60 запросов на сайт, включая поддомены. Плюс одна загрузка главной в браузере: 35–251 ресурс, включая сторонние счётчики и виджеты. Лимит 300 запросов на сайт соблюдён. Формы не отправлялись, входов и капч не было.

[ВЫВОД] Индекс видимости — относительный ранг сайтов по 9 коммерческим запросам Москвы. С визитами он не сопоставим и на органику в штуках не пересчитывается. Для оценки органики брать визиты Similarweb с оговорками выше и сверять с Keys.so после сброса лимита.

## Что нужно «Дому гирлянд», чтобы получить органику, и за какой срок

Сроки и пороги ниже — оценки по выборке 20 сайтов и 9 запросов. Они не учитывают будущие изменения алгоритмов Яндекса.

**Шаг 1. Основа сайта, 0–1 месяц.**
- Домен, HTTPS с переходом с http, robots.txt, sitemap.xml, Яндекс Вебмастер и Метрика.
- 25–40 страниц: главная; по странице на материал (профнастил, евроштакетник, рабица, 3D, жалюзи, дерево, кирпичные столбы); откатные ворота отдельным разделом из 4–6 страниц (с автоматикой, с калиткой, на сваях, промышленные — так устроены zaborovo.ru и ligazaborov.ru); цены и калькулятор; портфолио; FAQ; контакты и реквизиты.
- Разметка как у zabormo.ru и zaborkin.ru: LocalBusiness, Product + Offer с ценой, FAQPage, BreadcrumbList, AggregateRating.
- Один H1 с запросом, title до 70–80 знаков, canonical на себя, лёгкая главная (ориентир — zabormo.ru, 0,4 МБ).
- [ГИПОТЕЗА] Индексация основных страниц за 2–4 недели. Метрика — страниц в поиске по Вебмастеру. Порог — 80% страниц из sitemap.

**Шаг 2. Гео-слой, 1–4 месяца.**
- 30–60 страниц городов и районов МО на основном домене. Объём — по образцу zaborkin.ru (59) и zaborovo.ru (57).
- На каждой — объекты в этом городе с фото, цена, срок выезда бригады.
- Поддомены по образцу oblzabor.ru — следующий шаг, после проверки, что гео-страницы основного домена индексируются и получают показы. Причина — риск дублей.
- [ГИПОТЕЗА] Через 3–6 месяцев после публикации часть запросов «забор + город МО» и «материал + город» в топ-10. Метрика — показы и клики в Вебмастере по гео-запросам. Порог — 20% гео-страниц с кликами за 6 месяцев.

**Шаг 3. Объекты и ответы, постоянно с 1-го месяца.**
- Каждый выполненный забор — отдельная страница: материал, город, длина, цена, фото. Образцы — pro-zabor.ru (182) и moscow.kupitzabor.ru (699).
- Это содержание нельзя скопировать шаблоном, и оно же даёт уникальность гео-страницам.
- Раздел ответов на бытовые вопросы — по образцу dostup-zabor.ru (633).
- [ГИПОТЕЗА] 8–10 объектов в месяц с первого сезона монтажа.

## Что не удалось и почему

- **PageSpeed Insights** — квота API без ключа исчерпана (ответ 429). Вместо него — замер Playwright в облаке, только для сравнения.
- **web.archive.org** (история доменов) — соединение сбрасывается прокси среды. Возраст по whois — дата текущей регистрации. Для zabormo.ru и 33zabora.ru история сайта не подтверждена.
- **Индексация поддоменов и число страниц в индексе Яндекса** — без доступа к Вебмастеру владельцев и без запросов `site:` в выдаче (капча) не проверялись. Число URL на поддоменах — оценка: поддомены × URL в sitemap одного проверенного поддомена.
- **Полный список поддоменов kupitzabor.ru** — в HTML главной найдены 2 (moscow, arhangelsk), остальной выбор города подгружается иначе. Не найдено.
- **Видимость по городам МО** (выдача Одинцова, Подольска и т. д.) — Keys.so на прошлом этапе снят только по Москве. Эффект поддоменов и гео-страниц по своим городам не измерен.
- **Даты статей** у zaborovo.ru, raduga-zaborov.ru, pro-zabor.ru, dostup-zabor.ru на страницах блога не выводятся. Для трёх последних взят lastmod sitemap (дата изменения), у zaborovo.ru lastmod нет.
- **Точная частотность («!»)** — снята только по «забор под ключ» (14 205). Для остальных 8 запросов дневной лимит Keys.so исчерпан 20.10.2026; в варианте (Б) индекса применён коэффициент 0,248 — оценка.
- **Органика Similarweb** для 13 доменов (zabormo.ru, gorodzaborov.ru, zabory-deshevo.ru, zabor-vam.ru и др.) не снята этапом трафика (лимит Similarweb).
- **Классификация URL** по словам в адресе даёт погрешность. Пример: страница сотрудника pro-zabor.ru ошибочно попала в гео (1 URL), часть служебных страниц — в «прочее». В версии 2 исправлено ложное срабатывание «под старину» (основа «Старица»): у dostup-zabor.ru гео-страниц 413 вместо 414. Сводные числа гео-страниц проверены выборочно (по 8–10 адресов на сайт).
