## Источники и пути

- Wordstat: wordstat.yandex.ru → переадресация на passport.yandex.ru, форма «Введите номер телефона». Пользователь не залогинен, вход не выполнялся. Части А1–А4 через Wordstat не сняты.
- Keys.so: отчёт по запросу (`/ru/report?domain=<фраза>&db=msk`), база «Москва». График истории частотности выгружен из данных страницы. После второго отчёта сервис ответил «Превышен лимит анализируемых доменов за текущий день» (тариф не оплачен, лимит общий с другими агентами). Есть также раздел «Онлайн парсер Вордстат» (`/ru/wordstat-list`) — он расходует лимиты, не запускался.
- Google Trends (`geo=RU-MOW`, 01.10.2024–19.10.2026): график в интерфейсе пустой, повторные запросы к API вернули HTML вместо данных (ограничение частоты). Не снято.
- Подсказки Яндекса: suggest.yandex.ru, регион lr=213 (Москва), 20.10.2026.
- ВК: vk.ru в браузере пользователя (сессия уже открыта), десктопная стена, отзывы `vk.ru/reviews-<id>` с сортировкой «Сначала с низкой оценкой», обсуждение `topic-86599547_35694015`. Скриншоты на vk.ru расширение не разрешает («Permission denied for this action on this domain») — снимков объявлений ВК нет, тексты и ссылки на посты есть в vk_ads.csv.
- SeedHunter (seed.targethunter.ru → «Библиотека рекламы», `/wall-posts`): вход уже выполнен, бесплатный режим. Поиск по ключевым словам, фильтры: дата, охват, лайки, комментарии, репосты. Фильтра региона нет. Вкладка «По ссылкам» ищет посты по сообществу-площадке, по домену рекламодателя не ищет. Глубина выдачи — около 4 недель (23.09–19.10.2026). Запрос из 11 ключей сразу ушёл в бесконечную загрузку; по одному ключу ответ приходит за 20–40 секунд.
- Telegram: t.me/s/<канал> (публичная лента), пролистывание до 20.07.2026. TGStat: карточка канала открывается, статистика и поиск требуют входа — не сняты.
- MAX: публичные карточки max.ru. Число подписчиков без входа не показывается.
- YouTube: вкладка «Видео» каналов (Shorts не считались). Rutube: публичный API `rutube.ru/api/profile/user/<id>/` и `/api/video/person/<id>/`. ОК: ok.ru/masterovitru. Дзен: поиск dzen.ru по «мастеровит заборы».

## Что не удалось и почему

- [Закрыто 21.10.2026 выгрузками пользователя: «Динамика» 10 брендов и 4 запросов, «Регионы» 2 запросов.] Не выгружены «Топы запросов» по «откатные ворота» и динамика «установка забора» по остальной России. Исходно: Вордстат «Динамика», «Топы», «Регионы» по всем 7 запросам и 10 брендам — требуется вход в Яндекс ID, пользователь не залогинен. Нужен вход пользователя; после этого сбор занимает около часа.
- Keys.so — дневной лимит бесплатного доступа исчерпан после двух отчётов; история частотности снята только для «забор под ключ».
- Google Trends — ограничение частоты запросов.
